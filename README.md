# Old scripts
99% of these scripts won't work anymore, but some elements **DO WORK**. So feel free to analyse them and experiment to create new scripts.
Diep.io+ scripts are basically collections of small scripts, so you should definetly check those out.

# Sorting
I sorted the scripts into **canvas, memory, mixed, other and packet hook scripts.**

*Canvas:* scripts that get information through CanvasRenderingContext2d.prototype hooks.

*memory:* scripts that get information through WebAssembly.prototype hooks.

*mixed:* scripts that get infromation from both.

*other:* everthing else. (Bypasses, external libraries, HTML elements etc.)

*packet hook:* scripts that rely on ABC's packet hook (see diep in Depth on github).
